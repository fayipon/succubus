# NOCTIA 動作原型

已在 Spine Trial 4.3.23 實際匯入並預覽。

- idle：6 秒循環，呼吸、髮束微動、眨眼、胸部與衣料的低幅跟隨動作。
- hand_to_chest：包含待機動作，人物左手（觀眾右側）抬到胸前，約 1.45–3.4 秒停留，再放下；6 秒循環。

在 Spine 選擇「匯入資料」，載入 noctia-actions.json，圖片路徑保留 ./images/。動畫模式中，點動畫名稱左方的圓點切換，再按播放。

這是程式建立的 JSON 原始資料與素材，並非 Trial 匯出的檔案；未產生原生 .spine 工程，未接入網頁 runtime。Trial 無法儲存／匯出，關閉後可重新匯入這份資料。

目前使用 9 根骨架、5 個網格附件。左上臂／前臂／手掌分開控制，閉眼使用替換附件；髮束與軀幹仍由底圖的加權網格變形。仍有底色殘留、袖口接縫與部分髮絲邊緣，尚未達到完整精修拆層品質。胸部微動為預製關鍵影格，不是即時物理模擬。
