# NOCTIA v3：素材接縫清理

已在 Spine Trial 4.3.23 匯入，檢查待機、抬手中段與胸前姿勢。

- 重製完整左臂素材，從肩膀到手指使用同一張加權網格，取代三張互相重疊的切片。
- 肩部、肘部及手腕採漸變權重，降低斷縫和硬切邊。
- 重製手臂移開後的身體與髮束底圖。
- 經使用者授權，以 Python/Pillow 清除生成素材內的假棋盤格，產生真正 RGBA 透明背景，處理白邊與邊緣羽化。
- 眨眼附件邊界羽化；沿用 v2 的 8 秒動作節奏。

匯入 noctia-actions-v3.json，圖片目錄保留 ./images/。動畫名稱 idle、hand_to_chest。

素材由內建 imagegen 生成，再以程式清理。提示重點：保持原角色服裝與臉，補齊移除左臂後的身體和頭髮；另生成從肩膀到手指的一體式左臂，補齊髮束遮住的衣料。生成工具的透明輸出失敗，最終透明通道由程式處理。

此版消除了切片的幾何斷縫及大片背景殘留；仍是平面骨架動畫，極端彎肘有衣料壓縮感，細髮去背不等同人工逐髮精修。未整合網頁 runtime，沒有 Trial 匯出的原生 .spine 檔。
